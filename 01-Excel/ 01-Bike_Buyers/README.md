# Excel Project Dataset(Bike Buyers)

## Project Overview
This is an Excel data analysis project based on the Bike Buyers dataset.

## Objective
Explore the Bike Buyers dataset and use Excel to prepare, summarize, and visualize the data in order to better understand patterns associated with bike purchasing.

## Tools
- Microsoft Excel

## Skills Practiced
- Data cleaning
- Find and Replace
- Changing data types / cell formats
- Adding calculated columns
- `IF` and nested `IF` formulas
- Pivot Tables
- Dashboard creation and data visualization
- Excel Tables (formatted tables)
- Conditional Formatting

## Project Workflow
1. Reviewed the dataset and prepared a working copy.
2. Cleaned and standardized selected data.
3. Changed data types / formats where needed.
4. Added calculated columns, including age-group categorization using `IF` / nested `IF`.
5. Summarized the data using Pivot Tables.
6. Built a dashboard with charts and slicers to explore the data interactively.
7. Practiced Excel Tables and Conditional Formatting as additional skills.

 

## What I Learned
- How to clean and prepare a dataset in Excel.
- How to create calculated categories using logical formulas.
- How to summarize data with Pivot Tables.
- How to communicate patterns through charts, a dashboard, and slicers.
- How Excel Tables and Conditional Formatting support data handling and exploration.
